# Kommunikation
Kursen ger grundläggande kunskaper inom kommunikation med fokus på webbutvecklarens framtida yrkesroll. Under kursen behandlas kommunikation i team, kundrelationer, gruppdynamik, kommunikationsstilar, målgruppsanpassning, retorik och presentationsteknik.
